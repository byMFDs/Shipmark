# Shipmark

**Public proof of work for AI builders.**

Shipmark is where AI builders show what they actually shipped. Projects are
linked to GitHub repositories and verified domains, so visitors see evidence
instead of claims.

**Website:** https://shipmark.org

## What is on Shipmark

- Projects linked to GitHub repositories, with commit-based activity
- Verified hallmarks: repository owner and confirmed domain
- Ship Week: a weekly view of what was released
- Builder profiles with links to GitHub, X, LinkedIn and Telegram
- Eight languages: English, Ukrainian, Russian, Polish, German, Spanish, French and Portuguese (Brazil)
